Import creates a backup of an existing registry. Sensors remain “awaiting reconnect” until they communicate with this gateway.

Use persistent key and fallbackKey values. Temporary session keys cannot restore a sensor after reconnect. Extracted keys stay on this server and expire after 10 minutes. No factory reset is needed.
